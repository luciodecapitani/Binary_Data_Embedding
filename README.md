# Reproducibility Instructions

To reproduce the results presented in the submission **"Bidimensional Embedding and Visualization of Multidimensional Ordinal Binary Data"**, please follow the steps below:

1. Download all the files in this repository and save them in a folder (e.g., `BiDaEm`).
2. Open **R** and set `BiDaEm` as your working directory.
3. Install the CRAN package `poseticDataAnalysis` (if it is not already installed).
4. Open the script `Financial_literacy_GitHub_version_reproducibility_JCGS.R` and run it.

The script will reproduce all the numerical results and figures presented in the submission.
